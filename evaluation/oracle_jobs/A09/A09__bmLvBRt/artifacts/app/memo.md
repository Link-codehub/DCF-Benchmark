# A09 参考说明

铖序精工的估值由两个产品的投入量、良率和 BOM 成本链驱动。阿尔法阀组五期均受有效产能约束，贝塔执行器五期均由订单需求约束；因此扩产及利用率对阿尔法更直接，贝塔良率提升则在投入量不变时增加合格产量、销量和收入。基准企业价值为 5,684.29 百万元，股权价值为 5,616.29 百万元，每股价值为 67.93 元。

材料按各产品投入量和 BOM 单耗耗用，采购同时补足耗用和目标原材料余额，不直接计入销售成本。合金价格变化会传导至材料销售成本、原材料、应付账款及 FCFF；贝塔良率变化主要影响销量、销售成本结转和产成品。原材料、在制品和产成品分别按各自成本基础和天数估算，首期 NWC 增加使残余段 FCFF 为负，后续价值主要来自完整年度现金流和终值。

局限：这是原创虚拟企业的冻结假设模型，不是实际市场预测或投资建议。产能、订单、价格与付款条件未反映周期联动，终值现值占企业价值比重较高，永续增长和 WACC 的微小变化可能显著影响结果；敏感性网格只覆盖合金价格和贝塔良率。
