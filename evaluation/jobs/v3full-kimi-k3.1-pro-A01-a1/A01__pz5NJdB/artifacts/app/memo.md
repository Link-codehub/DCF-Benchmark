# 弦庭软科估值说明

估值日为 **2025-09-27**，最近完整财年末为 **2025-06-30**。模型以百万元、百万股和小数比率列示，使用五期 DCF；P1 为估值日至 2026-06-30 的 276 天残余期，P2–P5 为完整财年。所有预测均连接至 `Inputs` 原始假设，无外部工作簿链接。

## 核心方法与结果

- **ARR 与收入**：期末 ARR = 期初 ARR + 期初 ARR ×（净收入留存率 − 1）× 经营流量比例 + 年度新签 ARR × 经营流量比例。P1 仅将净扩张和新签按 276/365 计入，不缩减存量 ARR。收入 =（期初 ARR + 期末 ARR）/ 2 × 经营流量比例。
- **利润与自由现金流**：FCFF = EBIT ×（1 − 税率）+ D&A − 资本开支合计 − 营运资本增加。资本开支合计包括资本化研发和其他资本开支；SBC 已包含在 EBIT 经营成本中，不在 FCFF 加回。
- **营运资本**：期末余额 = 年化收入 × 营运资本比率。P1 虽只确认残期流量，期末余额仍按完整年度驱动，其增加额相对期初 63.0 百万元计算。
- **折现与终值**：期末惯例，折现时间 =（预测期末日 − 估值日）/ 365；终值位于 P5 期末，等于 P5 FCFF ×（1 + 永续增长率）/（WACC − 永续增长率）。
- **股权桥与股数**：企业价值加现金及投资，减债务、租赁负债和少数股东权益，并计入估值现金调整；稀释股数包括基本股数、RSU 和按库存股法计算的期权净增股数。

基准估值结果：企业价值 **425.62 百万元**，股权价值 **367.62 百万元**，稀释股数 **76.2 百万股**，每股价值 **4.82 元**。P1 FCFF 为 **−17.44 百万元**，主要受残期仍建立完整年度营运资本余额及资本化研发投入影响。

## 主要价值驱动

1. **净留存与新签共同扩大 ARR**：净收入留存率从 P1 的 104.0% 上升至 P5 的 106.0%，年度新签 ARR 假设从 98.0 增至 150.0 百万元；期末 ARR 从期初 730.0 增至 P5 的 1,578.0 百万元。收入增长由 ARR 滚动及平均 ARR 确认产生，而非单一收入增长率外推。
2. **经营杠杆**：EBIT 利润率从 16.0% 提升至 17.6%，推动利润增长快于残期年化收入基础上的可比增长。税率固定为 23.0%。
3. **再投资与现金转化**：D&A 为收入的 5.2%；其他资本开支为 6.5%，资本化研发为 7.5%，合计资本开支为收入的 14.0%；期末营运资本为年化收入的 13.0%。ARR 扩张虽提升长期现金流，也带来当期研发和营运资本占用。
4. **折现与永续假设**：WACC 为 10.0%，永续增长率为 2.5%。终值现值为 360.28 百万元，占企业价值约 **84.6%**，因此长期 ARR 增长、利润率及资本效率对估值尤其重要。

## 局限

- 输入没有历史财务序列、ARR 分层或客户队列数据，平均 ARR 是对收入确认时点的简化，无法区分新签月份、客户流失、扩容、价格变化及合同期限。资本化研发和其他比率亦按固定收入比例预测，缺少资产滚动及摊销年限验证。
- 终值贡献约 84.6%，估值对 WACC、永续增长率及 P5 FCFF 高度敏感。基准结果应视为给定假设下的模型价值，而非市场交易价格或投资建议。
