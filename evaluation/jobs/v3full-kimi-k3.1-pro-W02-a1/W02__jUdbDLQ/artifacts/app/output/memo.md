# Costco Wholesale Corporation（COST）五年 DCF memo

## 范围与取数日期

- 信息截止日为 **2024-10-31**，建模基准财年为 **FY2024**；流量期间为 2023-09-04 至 2024-09-01，资产负债表时点为 2024-09-01。
- 实际网络取数日期为 **2026-11-22（UTC）**。`sources.json` 的 `observed_at` 分别记录 SEC 文件和财政部 CSV 的实际取回时间，不把申报日误记为取数日。
- SEC 会计事实取自 `https://data.sec.gov/api/xbrl/companyfacts/CIK0000909832.json`。只接受 `filed<=2024-10-31` 的 10-K/10-K/A，按合同标签顺序选择首个具有合规原始单位、期间及申报记录的事实。
- 15 项 SEC 取数均来自 **2024-10-09 申报的 10-K**，登记号为 **0000909832-24-000049**。另用 `https://www.sec.gov/Archives/edgar/data/909832/000090983224000049/cost-20240901.htm` 的利润表、资产负债表和现金流量表核对同一事实；这不是第二个独立会计事实，也没有把后来重述值混入。
- 财政部取数 URL 为合同指定的 Daily Treasury Par Yield Curve Rates CSV。2024-10-31 当日存在非空 **10 Yr = 4.28%**，实际观测日就是 2024-10-31，模型写为 **0.0428**；题面 4.25% 仅为写法示例，本模型没有使用 0.0425。

完整字段、期间、标签、申报号、`filed`、`observed_at` 和本地原始文件名见 `sources.json`；所有 16 项状态均为 `ok`，`value` 均为实际数值。金额单位为百万美元，加权平均稀释股数为 444.759 百万股，资本开支按现金流出正数 4,710 百万美元记录。

## 开放预测假设

本模型不采用市场一致预期、现成目标价或股价。假设如下：

| 假设 | 基准值 | 理由 |
|---|---:|---|
| `initial_growth` | 6.00% | FY1 的开放名义收入增长假设，体现稳健增长而非历史增长率的机械重复。 |
| `steady_ebit_margin` | 3.6490% | FY2024 经营利润 9,285／收入 254,453，预测期保持该水平。 |
| `tax_rate` | 24.3634% | FY2024 所得税费用 2,373／税前利润 9,740。 |
| `da_to_revenue` | 0.8791% | FY2024 折旧摊销 2,237／收入 254,453。 |
| `capex_to_revenue` | 1.8510% | FY2024 资本开支 4,710／收入 254,453。 |
| `wacc` | 8.00% | 透明开放的名义折现率假设，不是外部现成估计。 |
| `terminal_growth` | 3.00% | 长期名义增长假设，低于 WACC。 |

FY1 使用 6% 增长，FY2–FY5 每年移动 `(terminal_growth−initial_growth)/4`，故依次为 5.25%、4.50%、3.75%、3.00%。财政部 4.28% 的十年期收益率只作为市场参照，不机械替代完整 WACC。

## 计算口径与结果

- 每年 EBIT=收入×稳态 EBIT 利润率，D&A=收入×折旧摊销比率，CapEx=收入×资本开支比率。
- FY0 经营 NWC=流动资产−现金−短期投资−（流动负债−当期债务）=34,246−9,906−1,238−（35,464−103）=**−12,259 百万美元**。FY1 ΔNWC=FY0 NWC×（FY1 收入／FY0 收入−1），其后为本年 NWC 减上年 NWC。负经营 NWC 反映流动经营负债高于合同口径内的流动经营资产；收入增长时 ΔNWC 为负，按公式增加 FCFF，这不是缺失值或补零。
- 应收账款 2,721 已包含在流动资产合计中，另在 `Assumptions!B18` 活公式展示，不再单独加入 NWC，避免重复计算。
- FCFF=EBIT×（1−税率）+D&A−CapEx−ΔNWC；五年 FCFF 分别约为 5,558.38、5,758.26、5,919.92、6,039.34、6,113.33 百万美元，按第 1–5 年离散折现。
- Gordon 终值=FY5 FCFF×（1+g）／（WACC−g），再乘 FY5 折现因子。股权价值=企业价值+现金+短期投资−当期债务−非当期债务；现金和短期投资没有计入 FCFF，只在股权桥中加一次。每股价值使用加权平均稀释股数，不使用期末股数。

基准重算结果：

| 输出 | 数值 |
|---|---:|
| `enterprise_value` | 109,091.55 百万美元 |
| `equity_value` | 114,338.55 百万美元 |
| `value_per_share` | 257.08 美元／股 |

这些是上述开放假设下的模型结果，不借助股价判断其合理性，也不构成投资建议。

## 交叉验证、失败与冲突

`cross_validation.json` 的 `pretax_to_net_income` 直接引用来源表的 `pretax_income`、`income_tax`、`net_income_consolidated`：

**9,740−2,373−7,367=0 百万美元。**

容差为 `max(0.01,abs(7,367)×0.02)=147.34` 百万美元，结果通过。`ProfitLoss` 为含非控股权益的合并净利润，没有与归母净利润混用。

本次没有取数失败、缺失事实或同标签合规事实之间的数值冲突，因此没有 `failed` 项，也没有为了勾稽或建模而改数、猜数或静默补零。应收账款在允许标签 `AccountsReceivableNetCurrent` 下没有合规事实，按顺序使用有合规事实的 `ReceivablesNetCurrent`；其余低优先级标签即使存在也不替代已选事实。财政部当日有值，因此未使用更早日期回退。

## 网络白名单的验证边界

运行时的 IPv4 请求对 `data.sec.gov`、`www.sec.gov` 和 `home.treasury.gov` 均返回 HTTP 200，记录了实际远端 IPv4 地址。本 memo 仅能据此说明**允许来源实际可达**，不能由 compose/task 配置文件的存在推断 sidecar 白名单已经生效。运行中没有对非白名单域名执行对照访问，因此**不宣称白名单拦截机制已经过独立验证**。

整个建模未访问或引用第三方财经网站、搜索摘要、股价、现成目标价或市场一致预期，也未使用截止日后才公开的会计或估值信息。
