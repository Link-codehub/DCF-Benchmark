# 砚川公用估值说明

## 结论

以 2026-04-22 为估值日，模型得到企业价值 **295.35 百万元**、股权价值 **207.35 百万元**、摊薄股数 **94.20 百万股**及每股价值 **2.20 元**。这是基于给定假设的模型结果，不构成投资建议；输入股价 15 元仅用于库存股法和市场对照，不参与 DCF 定价。

- 明确预测期 FCFF 现值：129.04 百万元。
- P5 期末终值：264.66 百万元；终值现值：166.32 百万元。
- 股权桥：企业价值加现金 193、投资 31及估值现金调整 0，减债务 281、租赁负债 19及少数股东权益 12，均为百万元。
- 摊薄股数为基本股数 93 加 RSU 1.2；期权数量和行权价均为 0，故期权不增加股数。

## 模型口径与追溯路径

`Inputs` 保留原始语义键、历史事实和 C/D/E… 向量。`Timeline` 生成日期、实际天数及折现因子；`Regulated Ops` 建立监管经营表；`DCF` 计算 FCFF 和终值；`Equity Bridge` 计算股权价值与摊薄股数；`Results` 唯一列示全部 52 个公开键，右邻均为活公式。`Checks` 汇总一致性检查。

预测共五期。P1 从估值日 2026-04-22 至 2026-11-30，共 222 天，经营比例为 222/365；其后为完整财年。折现时间从估值日起按累计实际天数/365 计算，五期分别为 0.608219、1.608219、2.610959、3.610959及 4.610959 年，采用期末折现。

监管经营表采用以下连接，而非单一收入增长率外推：

1. **资产滚存**：期末受监管资产基数 = 期初基数 + 资产新增 − 监管折旧回收。资产新增按 P1 经营比例计入，监管折旧 = 期初基数 × 监管折旧率 × 经营比例。
2. **收入**：监管收入 = 期初基数 ×（允许回报率 + 监管折旧率）× 经营比例，即允许回报与折旧回收之和。
3. **盈利**：EBIT = 监管收入 × EBIT 利润率；SBC 作为经营成本包含在 EBIT 内，FCFF 不加回。
4. **再投资**：现金流资本开支 = 监管收入 × 资本开支比率，D&A = 监管收入 × D&A 比率。
5. **营运资本**：期末余额 = 完整年度收入 × 营运资本比率；P1 完整年度收入为活动口径收入除以 222/365。营运资本变动为相邻期末余额之差，因此 P1 从期初 87 降至 20.748，形成 66.252 百万元释放，不对该变动再次按残期缩放。
6. **FCFF**：EBIT ×（1 − 23%）+ D&A − 资本开支 − 营运资本变动。终值为 FCFF₅ ×（1 + 2.5%）/（10.6% − 2.5%），落在 P5 期末并仅折现一次。

资产新增与现金流资本开支分别使用输入的绝对金额和收入比率驱动，不强制相等；监管折旧回收与现金流 D&A 同样按各自驱动计算。

## 主要价值驱动

- **监管资产与回收假设**：期初资产基数 1,520 百万元，年度资产新增从 90 增至 122 百万元；P5 期末资产基数为 1,742.48 百万元。允许回报率 6.8%及监管折旧率 3.7%共同形成收入基础，新增资产又通过滚存影响以后各期回报和回收。
- **利润率及再投资**：EBIT 利润率由 16.0%逐步升至 17.6%，提升 NOPAT；D&A 比率 5.2%、资本开支比率 6.5%及营运资本比率 13%决定现金流转化。
- **P1 营运资本释放**：P1 FCFF 为 76.95 百万元，显著高于后续完整年度，主要原因是 66.252 百万元营运资本释放。这是一次性余额标准化效应，不应被解读为可持续经营增长。
- **折现与终值**：WACC 10.6%、永续增长率 2.5%决定资本化倍数和现值。终值现值占企业价值约 56.31%，估值对折现率及长期增长假设高度敏感。

## 局限

1. **资产新增与现金流资本开支并未统一勾稽**。按基准输入，P5 资产新增 122 百万元，而现金流资本开支约 11.48 百万元；监管折旧回收与现金流 D&A 也不相等。输入未提供在建工程转固、资产新增确认时点或非现金资本开支明细，模型因此保留两套独立驱动。这会削弱资产滚存与自由现金流之间的经济一致性，是本次估值的主要局限。
2. **缺少历史财务序列和监管明细**。`History` 无实际数据，无法验证允许回报率、利润率、营运资本正常化水平及 SBC 金额，也无法判断 P1 大额营运资本释放是否可实现。
3. **终值延续 P5 利润率与再投资比率**，未单独构造稳态监管资产、资本开支和折旧回收的一致关系；终值依赖 Gordon 简化假设。
4. **现金、债务、投资、租赁及少数股权按输入账面值处理**，未提供市值、受限现金、税务或处置调整；RSU 全额摊薄和期权库存股法亦依赖输入条款的简化表达。

## 验证

已用 LibreOffice 对工作簿实际重算，全部 52 个公开键均为唯一数值活公式，无外部工作簿链接；`Checks` 全部通过。独立 Python 口径复算与全部公开键一致，最大绝对差约 4.8×10⁻¹²。三组临时扰动分别覆盖监管经营假设、WACC/永续增长率及股权桥与价内期权，均通过传播和独立复算检查；正式文件保留原始输入。
