# 砚川公用 — 估值备忘录

## 模型架构

采用受监管公用事业行业 DCF 模型（FCFE 路径的五期活公式表）。经营预测以**受监管资产基数（Rate Base）× 允许回报率**为核心驱动，而非单一增长率外推。资产基数经资本开支增厚、监管折旧回收滚动，收入通过隐含 EBIT 利润率反推。

- **P1（残余期）**: 估值日 2026-04-22 至财年末 2026-11-30（222/365 天），经营流量按天数比例计入。NWC 按完整年度收入驱动，期末 NWC 作为 P2 的期初值。
- **P2–P5（完整财年）**: FY2027–FY2030 末（11-30），各期为完整 12 个月。
- **终值**: Gordon Growth Model，以 P5 FCFF × (1+g) / (WACC − g) 计算，落在 P5 期末。
- **折现**: Actual/365 日计数，期末惯例。股权桥: EV − 负债 + 现金 + 投资。

## 主要价值驱动

| 驱动因素 | 影响机制 | 当前假设 |
|---|---|---|
| 允许回报率 | EBIT = 期初 Rate Base × allowed_return | 各期 6.8% |
| 监管折旧率 | 年度回收减少 Rate Base | 各期 3.7% |
| 资本开支强度 | capex_pct 驱动 Rate Base 增厚与现金流出 | 各期收入的 6.5% |
| 资产基数增额 | rate_base_additions 直接扩大 Rate Base | 90 → 122 逐年增长 |
| EBIT 利润率 | 收入 = EBIT / margin（隐含成本结构） | 16.0% → 17.6% 逐年改善 |
| WACC | 折现终端价值权重极大 | 10.6% |
| 永续增长率 g | 终端价值敏感度极高 | 2.5% |

终端价值占企业价值约 **70%**，模型对 WACC 与 g 的微小变动高度敏感，符合公用事业 DCF 的典型特征。

## 关键局限

**EBIT 利润率驱动的隐含成本结构缺乏运营细节**：收入由 EBIT / ebit_margin 反推，隐含地将所有非折旧运营成本压缩为收入的余项。对于受监管公用事业，现实中成本结构包括燃料采购、人力、维护、外购电力等独立动因，且监管机构可能仅允许特定成本项的回收，而非固定利润率。这意味着模型无法捕捉成本超支不能转嫁、或监管滞后调整对盈利的真实冲击——在经济周期转折或燃料价格波动时，实际现金流可能显著偏离模型预测。
