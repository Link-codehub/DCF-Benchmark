# 栖桐置业估值备忘录

## 估值口径

- 估值日为 2024-08-30，最近完整财年末为 2024-03-31；预测五期，P1 至 P5 分别截至 2025-03-31 至 2029-03-31。
- 金额单位为百万元，面积单位为平方米，股数单位为百万股；比率在模型中以小数存储。
- 按“可租面积 × 出租率 = 已出租面积”“已出租面积 × 单位年租金 = 租金收入”“租金收入 − 经营成本 = NOI”构建经营预测。
- 按题目指定口径，估值日物业价值直接等于 P1 NOI ÷ P1 NOI 资本化率，不对剩余期间折现，也不使用 FCFF 或 WACC。
- NAV = 估值日物业价值 + 现金 + 估值现金调整 − 债务 − 资本开支储备。股权价值 = NAV + 投资 − 租赁负债 − 少数股东权益。
- 稀释股数 = 基本股数 + RSU + 库存股法下的价内期权净稀释；每股价值 = 股权价值 ÷ 稀释股数。

## 主要价值驱动

1. **出租面积**：可租面积保持 98,000 平方米，出租率由 P1 的 91.0% 升至 P4/P5 的 94.0%，已出租面积由 89,180 平方米增至 92,120 平方米。
2. **单位租金**：单位年租金由 0.00310 增至 0.00342 百万元/平方米，与出租率提升共同推动 P1 至 P5 租金收入增长。
3. **经营成本率**：各期经营成本率均为 29%，对应 NOI 率为 71%；成本率变化会直接改变 NOI 和资本化价值。
4. **NOI 资本化率**：基准各期均为 6.10%。估值日价值以 P1 NOI 资本化，因此资本化率是关键估值假设；资本化率上升会压低物业价值。
5. **股权桥与稀释**：现金、债务、资本开支储备、投资、租赁负债、少数股东权益及估值现金调整决定股权价值；RSU 和价内期权影响每股价值。

## 局限

- 未提供历史经营数据或分资产、分租约明细，预测完全依赖给定假设；固定可租面积和统一资本化率未反映新增/处置物业、续租落差、空置恢复期及不同资产风险差异。
- 按指定简化口径，以完整 P1 NOI 直接资本化至估值日，未单独计入估值日至 P1 财年末之间的现金流或时间价值。因此，该结果不应与包含期间现金流折现的估值直接比较。
- 资本开支仅以估值桥中的储备扣减体现，未建立逐期资本开支、维修周期和租金激励的详细计划；实际可分配价值可能不同。
