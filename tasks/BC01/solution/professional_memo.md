# 栖岸云档 DCF 估值说明

## 预测期与历史口径

公司财年截至每年 8 月 31 日。五个预测期间为：

1. **P1 残期：2025-12-21 至 2026-08-31**，只包含估值日后的 253 天经营活动，活动比例为 253/365，约 69.315%。
2. **P2：2026-09-01 至 2027-08-31**，活动比例为 100%，是残期之后的首个完整财年。
3. **P3、P4、P5** 分别结束于 2028-08-31、2029-08-31 和 2030-08-31，均为完整财年。

`History` 上方原始半年度事实未作改写。FY2025 由 2024-09-01 至 2025-02-28 与 2025-03-01 至 2025-08-31 两个半年度相加：收入为 **1,043.892284**，规范化 EBIT 为 **182.352715**。截至估值日的 LTM 恰好也是这两个半年度，因此与 FY2025 相同，不再年化，也不重复拼接其他期间。

规范化 EBIT 的计算是“收入－不含 SBC 的经营成本－SBC”。SBC 作为经营成本保留；2025H2 单独披露的非经常收益 **6.244924** 不进入规范化 EBIT，只用于从规范化 EBIT 到报告 EBIT **188.597639** 的桥接。`History!C17:D19` 单独列示每一项非经常调整及合计。

## 主要价值驱动

### 1. 产能存量、利用率与价格

预测采用存量驱动而不是把参考产能增长率再次叠加：

- 期末产能 = 期初产能－期初产能×流失率＋新增产能。
- 平均产能 =（期初产能＋期末产能）/2。
- 完整年度收入 = 平均产能×利用率×单位收入。
- 当期收入 = 完整年度收入×活动比例。

因此，新增产能及其后续滚动、产能利用率由 74.0% 逐步升至 81.2%、单位价格逐期复合增长，共同决定收入。P1 完整年度收入为 1,146.539，但确认到残期经营的收入只有 794.725。`a.driver_growth` 仅保留为公开参考输入，不在存量方程中重复计入。

各期 EBIT 使用该期独立的核心利润率，利润率由 P1 的 16.0% 升至 P5 的 18.8%。SBC 备忘行按当期收入及公开比例计算，但不再次从 EBIT 扣减，也绝不在 FCFF 中加回；SBC 仅在三表 CFO 中作为非现金项目调整，并滚入 SBC 储备。

### 2. 再投资、营运资本与 NOL

资本开支按残期收入和当期资本开支率计算。PPE 按“期初＋资本开支－折旧”滚动，折旧采用期初资产加半期新增资本开支的基数及公开折旧率；模型按对应完整财年间隔的实际天数/365计算折旧，残期新增资本开支本身已经通过残期收入缩放。租赁和无形资产模块未在本题启用，因此相关新增不擅自进入预测，估值日既有租赁负债仍保留在股权桥。

期末营运资本按**完整年度**驱动，而不是按 P1 残期余额简单年化：

- 应收账款 = 完整年度收入×DSO/365。
- 存货 = 完整年度 COGS×DIO/365。
- 应付账款 = 完整年度 COGS×DPO/365。
- NWC = 应收＋存货－应付－合同负债。

P1 的期初 NWC 明确采用估值日余额 **368.678**，P1 期末 NWC 为 **176.284**，所以 ΔNWC 为 **-192.394**，构成残期现金流入；之后各期使用相邻期末余额之差。`Working Capital` 和 `Statements` 均显示该口径并互相勾稽。合同负债模块未启用，余额为零；若启用，现金收款只按“收入＋合同负债增加”计算一次。

无杠杆现金税以正 EBIT 为限，NOL 抵扣不超过期初可用余额或正 EBIT。P1 因使用 NOL，无杠杆现金税仅 **1.602**，期末 NOL 降为零。利息不进入 FCFF，但在三表中形成利息税盾和杠杆税项。

### 3. FCFF、折现及终值

每一期的 FCFF 均在 `DCF` 中完整展示：

> FCFF = 规范化 EBIT－无杠杆现金税＋折旧摊销－资本开支－ΔNWC

五期 FCFF 基线分别约为 **316.709、111.811、124.481、155.624、171.719**。P1 的高 FCFF 主要受前述营运资本释放影响，不应机械视为可持续现金流。

显性期按实际天数/365及年中惯例折现：期末折现年数 =（期末日－估值日）/365；FCFF 折现期 = 期末折现年数－活动天数/365/2。`DCF!D9:H12` 独立显示期末折现年数、年中调整、FCFF 折现期及折现因子。P1 折现期为 0.346575 年，P5 为 4.195890 年。

Gordon 终值直接引用 P5 FCFF、WACC 10.7% 和永续增长率 2.3%，即 P5 FCFF×(1+g)/(WACC－g)，基线为 **2,091.290**。终值位于最后完整财年末 2030-08-31，按 P5 的期末折现年数 **4.695890 年**折现，而不是使用年中折现期。当前 Gordon 权重为 100%，所以退出法结果按规则为零；P5 EBITDA 与 7.8 倍退出倍数仍作为可见辅助指标保留。若未来调整权重，采用终值会按两种方法加权。

## 股权桥与稀释股数

企业价值至股权价值使用**估值日**输入，而非预测期末余额：

> 股权价值 = 企业价值＋现金 109.400＋估值日现金调整 13.128＋投资 16.410－债务 218.800－租赁负债 0－少数股东权益 13.128

稀释股数 = 基础股数 140.000＋RSU 2.400＋期权库存股法增量。期权数量为 6.000 百万股，行权价 7 元，库存股法采用股价 14 元，因此增量为 3.000 百万股，总稀释股数为 145.400 百万股。每股价值由股权价值除以该稀释股数得到。

本题未启用 CAPM 模块，因此 WACC 直接采用公开假设 10.7%，`levered_beta` 和 `cost_of_equity` 按题目规则以活公式返回零；其他 CAPM 输入仍原样保留，不代表本模型另行推算了股权成本。

## 三表勾稽与模型导航

`Statements` 从 EBIT、利息和杠杆税项得到净利润，再滚动留存收益与 SBC 储备。CFO = 净利润＋D&A＋SBC－ΔNWC；期末现金 = 期初现金＋CFO－资本开支＋新增借款－偿债。现金从 `opening_cash` 滚动，利息基于期初债务及半期新增借款，避免现金利息循环。资产与负债权益的逐期差额、现金链接差额及 NWC 口径差额均在 `Checks` 集中显示，容差为 1e-6。

- `Summary`：估值结论、五期关键指标和口径导航。
- `Inputs`：原始语义键、原始 C/D/E… 向量及逐项中文用途说明。
- `History`：原始半年度历史，以及 FY2025/LTM 与非经常调整。
- `Operating`：期间、产能、价格、收入、利润率、SBC、NOL 和现金税。
- `Working Capital`：周转天数、期末余额、ΔNWC 和现金收款。
- `PPE & Debt`：PPE、ROU、D&A、债务、利息和税盾。
- `Statements`：净利润、CFO、现金、资产和负债权益勾稽。
- `DCF`：FCFF 桥、可见折现期、终值、股权桥和稀释股数。
- `Checks`：三表、NWC、FCFF、股权桥及结果键数量检查。
- `Results`：258 个公开键在 A 列各出现一次，B 列全部为指向明细页的数值活公式，C:E 列提供中文说明、单位和来源单元格。

## 具体局限与使用提醒

1. **P1 营运资本释放不可持续。** P1 ΔNWC 为 -192.394，显著抬高残期 FCFF；其驱动是估值日 NWC 368.678 与完整年度周转天数模型期末值 176.284 的差额，而不是可重复的经营改善。若把 P1 FCFF 直接年化或作为永续基数，会明显高估价值。
2. **终值占比高且依赖长期假设。** 基线终值现值约占企业价值 64.0%，WACC 10.7%、永续增长率 2.3% 和 P5 FCFF 的小幅变化都会对每股价值产生较大影响。P5 FCFF 本身也受终期利润率、资本开支及 NWC 假设约束，不能视为确定事实。
3. **冻结假设未覆盖全部现实风险。** 本模型未获得订单、客户集中度、产能投产进度、价格竞争、实际税务抵免限制及租赁/无形资产新增计划等明细；未启用模块按公开规则处理，并不等于这些项目在真实企业中永远为零。历史仅覆盖有限半年度，LTM 又恰等于 FY2025，无法提供额外的近期趋势信息。
4. **每股价值不是目标价或投资建议。** 这是原创虚拟主体的条件估值，库存股法采用公开股价 14 元而非模型反推价格，WACC 也是直接输入；实际决策还需要独立尽调和情景/敏感性分析。
